Hypomnema · Desktop mock-ups

Static HTML concepts for docs/REQUIREMENTS.md. Sample date: Saturday, Nov 14, 2026. Use the yellow MOCK button to review the dark theme. See also the phone set.

Proposals for the items deferred to mock-ups (Section 11)

  • Desktop layout: a navigation rail with Dashboard, Journal, and Archive. Goal details open beside the goal list; the journal list sits beside the selected entry. Entry, resource, slip, and archive forms are dialogs. Add Goal and Edit Goal are side sheets.
  • Sign Out: at the bottom of the navigation rail, separated by a divider. It asks for confirmation before signing out.
  • Mood colors: the number is always shown, in near-black, on every color in both themes.
