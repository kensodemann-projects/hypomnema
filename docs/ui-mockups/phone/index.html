Hypomnema · Phone mock-ups

Android phone layout (412 × 892) for docs/REQUIREMENTS.md, using the same sample data as the desktop set. Use the yellow MOCK button to review the dark theme.

Phone layout decisions

  • Bottom navigation bar with Dashboard, Journal, Archive, and Sign Out as the fourth item, matching the bottom of the desktop rail. Sign Out asks for confirmation, so a stray tap doesn't end the session.
  • Full-screen pages for goal details, both entry forms, the journal entry, the journal editor, Add Goal, Edit Goal, and resources. Forms use the close + Save top bar, so Save stays visible above the keyboard.
  • Dialogs only for short confirmations: record slip, archive, delete, and sign out.
  • Tabs in goal details (History, Entries, Resources) keep the page short. Desktop shows these side by side.
  • Mood charts scroll sideways for the 30-day and 1-year views, so each point keeps a readable number.
  • Delete is the only action on an archived goal, in its top bar (§3.5, §7.4).
