# Hypomnema

A hypomnema is a note kept so it can be found again: a reminder, a memorandum, an excerpt, or a short record of something worth remembering. In the plural, hypomnemata were the notebooks kept for that purpose, pages of quotations, observations, and things heard or read, gathered so they would still be there later.

Hypomnema is a personal application to help the user meet various daily, weekly, and monthly goals. These goals can take many forms such as "meditate daily," "exercise four times per week," or "lose twenty pounds by the end of the year." The user can track how they are performing against these goals as well as collect other information pertaining to each goal.
