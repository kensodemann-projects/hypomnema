# Hypomnema

A hypomnema is a note kept so it can be found again: a reminder, a memorandum, an excerpt, or a short record of something worth remembering. In the plural, hypomnemata were the notebooks kept for that purpose, pages of quotations, observations, and things heard or read, gathered so they would still be there later.

Hypomnema is a personal application to help the user meet various daily, weekly, and monthly goals. These goals can take many forms such as "meditate daily," "exercise four times per week," or "lose twenty pounds by the end of the year." The user can track how they are performing against these goals as well as collect other information pertaining to each goal.

## Journaling

- has a goal associated with it (daily, 3 times per week, etc)
- key data:
   - Date/Time
   - Subject
   - Mood (scale of X (3 or 5, has not been determined yet))
   - Journal (long form text)
- workflows:
   - configuration: set the goal
   - view: progress towards goal, list of past entries, can review past entries, can only edit an entry with today's date, can delete any entry though that will need to still count towards goal
   - journal: create a new entry
   - tracking: display how the user is tracking towards to goal on the dashboard

Within the journal entry the "I'm Stuck" feature provides a random prompt for something to journal about.

## Goals

### Setting Goal

- what is the goal?
- how is it tracked? (for example: times per day / week / month, value by target date )

### Tracking Workflow

- keep it simple
- depends on how the goal is tracked
   - could just be a check box to say "I did this"
   - could be the user entering a value
- includes an optional note for the entry

### Observations and Notes

Users can create other observations or notes associated with a goal

### Viewing Workflow

The "dashboard" should have a panel showing current tracking towards goal.

The panel clicks through to a view with details that include individual tracking entries and any collected notes and observations.
